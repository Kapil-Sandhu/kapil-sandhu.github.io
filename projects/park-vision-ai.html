1. Executive Summary & Surveillance Challenges

Automated parking management, toll barrier actuation, and urban traffic monitoring require continuous vehicle tracking paired with precise license plate recognition. However, real-world deployment faces four primary structural challenges:

⚠️ 1. High False-Positive Plate Extraction

Running unconstrained text recognition across full 1080p frames triggers false detections on billboards, shop signs, and roadside reflections. Park-Vision AI resolves this by applying a two-stage cascaded architecture that strictly isolates license plate search to localized vehicle bounding boxes.

⚠️ 2. Optical Character Ambiguity

Standard OCR engines routinely misclassify visually identical pairs (e.g. 0↔O, 1↔I, 5↔S). Park-Vision AI implements context-aware syntax heuristics that cross-reference position-specific alphanumeric expectations.

⚠️ 3. Transient Dropouts & Occlusions

Vehicles momentarily obscured by lampposts, overhanging trees, or adjacent traffic suffer identity fragmentation. Our SORT Kalman tracking coupled with Scipy 1D linear trajectory interpolation bridges multi-frame gaps seamlessly.

⚠️ 4. Jittery Video Visualizations

Flashing noisy intermediate character outputs each frame creates distracting visual noise. The Confidence Maximization Engine locks onto the single highest-confidence crop per tracked vehicle lifespan to render stable visual banners.

🔤

2. Domain-Specific Syntax Validation & Error Disambiguation

Optical character recognition models trained on general text struggle with embossed metal license plates under varying illumination, specular reflections, and dirt. Park-Vision AI eliminates over 85% of character confusion errors by enforcing strict structured alphanumeric syntax rules:

🖼️ Plate ROI Image Preprocessing (`format.py`)
  1. Crop Sub-Region: Extract localized plate tensor from the full raw RGB video frame.
  2. Grayscale Conversion: cv2.cvtColor(crop, cv2.COLOR_BGR2GRAY) to eliminate chrominance noise.
  3. Inverted Binary Thresholding:
    cv2.threshold(gray, 64, 255, cv2.THRESH_BINARY_INV)
    Isolates high-contrast characters as white foreground on pure black background.
  4. EasyOCR Inference: Character extraction executed with English alphanumeric dictionary.
⚡ Standard 7-Character License Syntax (`LLNNLLL`)
L L N N L L L

Positions 0, 1, 4, 5, 6 (Letter Slots): Enforces mapping from integer confusion characters back to letters:

'0'→'O', '1'→'I', '3'→'J', '4'→'A', '6'→'G', '5'→'S'

Positions 2, 3 (Number Slots): Enforces mapping from letter confusion characters back to digits:

'O'→'0', 'I'→'1', 'J'→'3', 'A'→'4', 'G'→'6', 'S'→'5'

3. Module-by-Module Technical Architecture & Data Schemas

📄 main.py · Video Ingestion & Detection Pipeline
  • Streams frames from input_video.mp4 via OpenCV video captures.
  • Executes yolov8n.pt vehicle detection and updates SORT tracker state vectors.
  • Runs custom models/best.pt license plate localized inference.
  • Logs raw detections and OCR extractions directly to tabular test.csv.
📄 format.py · Helper Utilities & Syntax Engine
  • get_car(): Performs spatial bounding box containment matching.
  • read_license_plate(): Converts plate crop to inverted binary mask and runs EasyOCR.
  • license_complies_format(): Evaluates 7-character structural pattern.
  • format_license(): Applies character substitution dictionary heuristics.
📄 data.py · Scipy Trajectory Gap-Filling Engine
  • Reads raw frame logs from test.csv and groups rows by unique car_id.
  • Scans for frame skips ($\Delta f > 1$) during occlusion or temporary tracker dropout.
  • Computes missing vehicle and plate coordinates via scipy.interpolate.interp1d.
  • Exports fully continuous, unbroken tracking telemetry to final_test.csv.
📄 video.py · Visualization Engine & Video Synthesis
  • Queries final_test.csv for the peak OCR confidence frame per vehicle lifespan: $\max(\text{score})$.
  • Renders sleek corner bracket borders in green (#00FF00) around tracked vehicles.
  • Overlays enlarged, crisp plate crops and high-contrast text banners directly above vehicles.
  • Encodes and writes final annotated video to output_video.mp4.
📊 Telemetry CSV Schema (`test.csv` & `final_test.csv`) 7 Core Columns
Field Name Data Type Description
frame_nmr Integer Sequential video frame index (0-indexed).
car_id Float / String Persistent tracking ID assigned by SORT tracker.
car_bbox String `[x1 y1 x2 y2]` Spatial pixel coordinates of the localized vehicle.
license_plate_bbox String `[x1 y1 x2 y2]` Bounding box coordinates of the detected license plate.

license_number String Syntax-validated and error-corrected alphanumeric text string.
license_number_score Float Cumulative EasyOCR confidence score ($0.0$ for interpolated frames).

5. Limitations & Future Engineering Enhancements

1. International Format Generalization

Current implementation assumes a strict 7-character template (LLNNLLL). Future iterations will introduce dynamic regex format catalogs supporting EU, US, UK, and Indian license plate geometries.

2. Foreground IoU Containment

Replacing strict geometric box-in-box matching in get_car with an Intersection over Foreground (IoF) metric to handle partial boundary occlusions during camera perspective skews.

3. GPU Batch Inference Acceleration

Enabling CUDA hardware acceleration (gpu=True) and TensorRT FP16 quantization across EasyOCR and YOLO heads for multi-stream >120 FPS edge servers.

4. Real-Time Telemetry & Database Webhooks

Integrating REST API endpoints and Redis Pub/Sub events to push vehicle timestamps, plate strings, and high-res crops directly to automated parking management databases.
